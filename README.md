# Sistema de Lançamento de Compras

Aplicação Java desenvolvida em Orientação a Objetos para controle de limite e registro de compras em cartão de crédito, com ordenação automática dos itens por valor.

## 🛠️ Tecnologias e Conceitos Utilizados
- Java
- Programação Orientada a Objetos (POO)
- Interface `Comparable` para ordenação de coleções (`Collections.sort`)
- Estrutura de dados `List` / `ArrayList`
- Manipulação de entrada/saída no console via `Scanner`
